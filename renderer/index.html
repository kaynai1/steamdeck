版本检查与更新 v2.6.59 旗舰版

版本更新说明

点「重新检查」联网检查最新版本；默认从 GitHub Releases 检查。
v2.6.84 更新特性：
1. 上架前令牌检查：批量上架开始前会检查当前账号是否导入了手机令牌（maFile）——未导入就明确弹窗告知「挂单需要手机确认」，可选择继续或先去导入；已导入则确认弹窗里写明「上架后软件自动确认，无需手机」。此前是挂完单才发现要掏手机；
2. 导入令牌弹窗补齐「手机官方令牌怎么办」：maFile 无法从手机直接导出——需要用 Steam Desktop Authenticator（SDA）迁移一次生成；弹窗里写清完整步骤与 Steam 的 7 天交易/市场限制期提醒；
3. 过时文案修正：饰品卡片说明、上架确认弹窗里的「需要在手机令牌确认」改为按实际令牌状态显示（导入=自动确认 / 未导入=手机确认）；
v2.6.83 更新特性：
1. 修复检查更新报「HTTP 403」：GitHub API 匿名额度按 IP 每小时 60 次——开 Clash 系统代理时走机场共享节点，额度被上百人分摊，403 几乎必现。现在检查更新改为三级通道：① 正常检查 → ② 若 403/429 自动用直连出口重试（api.github.com 国内直连多数可达，换成自己的 IP 额度另算）→ ③ 仍不通则走 GitHub Releases RSS 备用源（网页资产、不受 API 限额限制）；
2. 错误提示人话化：限流时会明确说明「GitHub API 匿名额度用尽，常见于代理/共享出口 IP」，并给出指引，不再是干巴巴的 HTTP 403；
v2.6.82 更新特性：
1. 育碧新增「浏览器登录取票」备用通道：内嵌登录窗口被育碧风控拦截（「访问暂时受限」且无验证入口、换代理也没用）时，点弹窗里的「① 在我的浏览器打开登录页」→ 在你平时能正常登录育碧的浏览器里完成登录 → 「② 复制登录后地址栏的完整网址」粘贴回软件 → 点「提取登录」即完成登录。原理：登录成功的网址里自带官方票据，软件直接提取，绕开内嵌窗口被反爬拦截的问题；
2. 修复风控页提示条从不出现的 bug：此前按「标题含 WebAuth」判断是不是登录页，而风控页的标题同样显示「登录 | Ubisoft WebAuth」，导致提示条永远不注入；现改为按「页面里有没有邮箱/密码输入框」判断——风控页会正确显示橙色的操作提示条；
3. 登录前只清会话 Cookie（UserID / sid / Ubi-Webauth），保留 DataDome 反爬信任 Cookie——修复「每次登录都被当成全新设备重新风控考核」；
v2.6.81 更新特性：
1. EA / 暴雪登录窗口改为强制直连：修复「ERR_PROXY_CONNECTION_FAILED」——此前这两个窗口跟随 Windows 系统代理，当 Clash 退出但系统代理开关残留（指向已关闭的端口）时登录页打不开；现在和育碧一样默认直连（等直连生效后再开窗），直连失败时才自动回退代理重试；
2. 风控拦截页不再闪退：育碧/EA/暴雪登录窗口命中「访问暂时受限」风控页时，不再自动关闭，改为在页面顶部注入橙色提示条——若页面有「我不是机器人」验证可直接完成后继续登录；若无验证入口则按提示换网络（家庭宽带直连，完全退出 Clash 含 TUN）后重试；
3. 登录失败提示全面人话化：代理失败、直连失败分别给出对应原因与操作指引；
4. 修复「没填账号密码直接显示已登录」的真正根源：EA / 暴雪登录窗口内残留一层宽松判定——官方首页匿名访问会种 8 个以上跟踪 Cookie、页面不在登录域名列表内，就被误判「登录成功」并自动关窗；现在窗口只在命中真实会话 Cookie（EA=remid、暴雪=BA-token/BA-sessionid，暴雪另有接口验真）时才算登录成功；
v2.6.80 更新特性：
1. 修复育碧登录窗口仍被风控：2.6.79 的直连设置是异步的、没等生效就打开了页面，窗口打开瞬间的请求仍可能走系统代理（Clash 香港节点→机房 IP→「访问暂时受限」）；现在先让直连真正生效再打开官方页面，并且每次登录前自动清除上次残留的风控 Cookie（DataDome 会记住"被判机器人"的状态）；
2. 登录页加载失败显示具体错误码：不再白屏，方便排查网络问题；
3. EA / 暴雪"没登录却显示已登录"：该修复从 v2.6.79 起生效（精确 Cookie 名单 + 暴雪接口验真身），请确认软件左上角版本号为 2.6.79 及以上；
v2.6.79 更新特性：
1. 育碧登录窗口改直连：此前官方登录窗口跟随了 Clash/系统代理，出口变成香港机房 IP，被育碧风控识别为机器人（「访问暂时受限」页面）；现在官方页面强制直连、和浏览器直登完全一致，命中风控页时会弹出明确指引（提示关闭 Clash 含 TUN 模式）；
2. 修复 EA / 暴雪「没登录却显示已登录」：登录判定改为精确 Cookie 名单（EA=remid，暴雪=BA-token/BA-sessionid），匿名访问种的 XSRF-TOKEN / sessionTrackingId 等跟踪 Cookie 不再被误判；暴雪还额外用账号接口验真身；
3. 修复平台页副标题残留：「EA 促销精选 · 0 款在售」等残留字样已清掉，副标题按账号游戏库显示；
v2.6.78 更新特性：
1. Ubisoft 登录彻底修复：新增「育碧官方登录窗口」——和你在浏览器登录育碧官网完全同一页面（connect.ubisoft.com），国内多数网络可直连、无需 Clash；登录成功自动捕获官方票据并读取「我的游戏」。之前失败的根本原因也查清了：旧版接口域名 public-ubiservices.ice.ubisoft.com 已无 DNS 记录（域名不存在），现已换成实测可达的 public-ubiservices.ubi.com；
2. 暴雪战网「我的游戏」接入：GitHub 调研找到账号页背后的 games-and-subs 接口（BAKLOG 等开源项目同款方案），官方窗口登录战网后自动列出账号拥有的全部暴雪游戏（魔兽世界 / 暗黑破坏神 / 守望先锋 / 炉石传说等）；
3. EA 结论说明：EA 云端账号库接口已随 Origin 关停彻底下线（实测返回 Origin has shut down），GitHub 上 Origin 类开源插件依赖的也是同一批已下线接口，EA 页保留说明；
4. 平台页去掉促销精选：Ubisoft / EA / 暴雪三个游戏库页不再显示促销清单，只保留账号游戏库与登录入口；
v2.6.77 更新特性：
1. Ubisoft 登录失败改为人话指引：登录、两步验证、拉取游戏库任何一个环节连不上育碧服务器，都不再甩英文报错——统一换成一句话指引：报「域名解析失败 / NAME_NOT_RESOLVED」= 没开代理；① 开 Clash / v2rayN 系统代理，② 或在「设置 → 登录窗口代理」填好代理地址后重试；UU 加速器是进程级加速、对此无效；
2. 登录弹窗提示更新：育碧登录窗口下方新增常见问题说明，登录前就能看到「开代理」提示，不用等报错再排查；
3. EA / 暴雪页说明重写：说清为什么没有像 Steam 那样的「我的游戏」——两家官方不提供账号库接口（实测 EA 旧 Origin 接口已随 Origin 关停而销毁、战网未开放），游戏库数据只在它们的桌面客户端内部；不是没接，是官方不存在这个接口，日后开放会第一时间跟进；

库存变动
只监控有网页会话的账号；每 6 小时对比一次「Steam 社区物品 + 自定义 AppID」，减号表示卖出或被交易走。
自动补货
只对当前网页登录的账号生效：发现新的成交后，如果库存里还有同款（可上架、不在冷却、没挂着），自动按当前最低价 -0.01 重新挂上。手动下架的物品不会被补回去。
补货同样受风控与手机令牌确认约束；没有行情或同款都在冷却时会跳过。
智能定价建议
快速价 = 当前最低价 -0.01 与近 7/30 天成交 p25 的较低值；保守价 = 近 30 天成交中位数。点某一行的价格会把它设为该件的改价目标，底部按钮可整批套用。
改价 = 先下架再上架，会触发手机令牌确认；执行前还有一次二次确认。
