# SteamDesk

Steam 多账号管理 + 游戏库识别 + 饰品行情对照 + 批量上架工具。
本地 Electron 桌面应用，**不接触账号密码**，不做全自动挂单循环。

---

## 一、它到底做什么

一句话：**帮你看清"该挂多少钱"，然后把上架动作做成一个可控队列。**

```
登录 Steam（网页，手输密码）
        ↓  拿到 Cookie
扫描本地 loginusers.vdf → 识别你所有的 Steam 账号
        ↓
拉取库存（appid 730 / 570 / 252490 / 440）
        ↓
逐个对照 Steam 市场最低价 / 中位价
        ↓
按策略或手填，定出每件的挂单价，实时显示到手净收入
        ↓
确认后逐件上架，记录 listingid
        ↓
市场挂单页可下架；改价 = 下架后重新上架
```

## 二、安装

需要 Node.js 18+（推荐 20）。

```bash
npm install
npm start
```

打包 Windows 安装包：

```bash
npm run dist          # NSIS 安装版
npm run dist:portable # 免安装单文件
```

产物在 `release/` 目录。

## 三、第一次使用

### 1. 确认 Steam 路径

启动后看左下角。如果显示"未探测到"，点右上角齿轮 → 选择 Steam 安装目录
（通常是 `C:\Program Files (x86)\Steam`）。

### 2. 扫描账号

概览页点"扫描账号"。它会读 `config/loginusers.vdf`，列出这台机器上登录过的所有账号。

> 注意：只能看到**至少登录过一次**的账号。全新机器扫不出东西是正常的。

### 3. 获取市场 Cookie（拉库存/上架的必要条件）

账号管理页点某个账号的"登录"按钮 → 弹出 Steam 登录窗口 → 手输账号密码完成登录。

Cookie 会用系统密钥环（Windows DPAPI / macOS Keychain）加密后保存。
**如果你的系统不支持加密，程序会拒绝保存，而不是明文落盘。**

### 4. 拉库存并查价

饰品仓库页 → 选账号 → 选游戏 → "重新拉取" → "查询行情"。

查价是串行的，注意看进度提示。接口没有官方配额，**实测约每分钟 20 次后开始返回 429**，
程序会自动退避重试。

### 5. 定价与上架

- 选"跟随最低价 −¥0.01"这类策略，点"应用策略到全部"
- 或直接把价格**手填**进每行的输入框
- 每行右侧实时显示"到手"= 挂单价 ÷ 1.15（Steam 抽 15%）
- 勾选物品 → "批量上架" → 弹出总额确认 → 确认执行

### 6. 下架

市场挂单页 → "同步挂单" → 找到目标 → "下架"。

## 四、几个必须知道的坑

### 价格单位是"分"

上架接口的 `price` 字段单位是**分**。1286.00 元要传 `128600`。
代码内部统一用"元"进出，换算只在 `main/seller.js` 里发生一次。
少写一个零就是少赚 10 倍，所以这里不省事。

### 改价没有接口

Steam 不提供改价 API。所谓"改价"= 下架 + 重新上架，listingid 会变。
所以软件里的改价流程就是走这两个动作。

### 上架逐件发请求

`assetid` 是单件粒度，有 4 件就得发 4 次请求，没有批量接口。
默认间隔 4 秒，太快容易 429。

### 三道拦截

以下情况会**在上架前**被拦下，不会走到请求那一步：

| 情况 | 处理 |
|---|---|
| `marketable=0`（不可在市场出售） | 拦截 |
| `tradable=0`（交易冷却中） | 拦截，并显示什么时候解冻 |
| 无行情数据 | 拦截，要求手填 |
| 价格低于市场最低价的 70% | 拦截（防少打一个零） |
| 价格高于最低价 150% | 放行但警告"可能长期卖不掉" |

## 六、账号切换原理

切号不是模拟登录，而是**改 Steam 自己的自动登录配置**：

1. 可选先关掉 Steam（配置被占用会写不进去）
2. 备份 `config/config.vdf`
3. 把 `InstallConfigStore.Software.Valve.Steam.AutoLoginUser` 改成目标账号
4. 重启 Steam 客户端

前提条件（缺一不可）：
- 该账号之前在客户端勾选过"记住密码"
- 存在对应的 `ssfn*` 凭证文件

不满足的话，切换会失败并告诉你具体缺什么，而不是静默失败。
**切换过程不读取、不存储、不传输任何密码。**

## 七、风险与边界

- 自动化操作 Steam 市场处于用户协议灰色地带，**账号风险由使用者承担**
- 同一 IP 下多账号高频操作容易被风控标记，建议间隔放长
- 价格填错无法撤回（只能下架重挂），这也是加了三道拦截的原因
- 本项目不提供任何自动交易、自动扫货、跨账号搬运功能

---

## 八、当前版本已知限制

- 仅支持 Windows / macOS 桌面端（需本机有 Steam 客户端）
- 游戏库"已拥有游戏"部分需要 Steam Web API Key（可选，不填则只看本地已安装）
- 行情查价受 Steam 限流影响，库存很大时需要分多次跑
- 授权层目前完全放行，收费版本需要自行接服务端校验
